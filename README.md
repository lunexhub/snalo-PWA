# Snalo Fast Delivery

An on-demand grocery delivery web application demo designed for speed, intuitive cart flow, and real-time order tracking.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **Frontend**: [React 19](https://react.dev)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) & [tw-animate-css](https://github.com)
- **UI Components**: [Radix UI](https://www.radix-ui.com) & [shadcn/ui](https://ui.shadcn.com)
- **State & Query**: [TanStack Query](https://tanstack.com/query)
- **Icons**: [Lucide React](https://lucide.dev)
- **Build Tool**: [Vite](https://vitejs.dev) & [Nitro](https://nitro.build)

## Getting Started

### Prerequisites

You can use either [Bun](https://bun.sh) or [Node.js](https://nodejs.org) (v20+):

### Installation

```sh
bun install
# or
npm install
```

### Development Server

Start the local development server:

```sh
bun dev
# or
npm run dev
```

### Build

Create a production build:

```sh
bun run build
# or
npm run build
```

### Testing

Run tests with Vitest:

```sh
bun test
# or
npm test
```
